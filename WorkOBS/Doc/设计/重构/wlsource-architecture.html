WLSource 协议化重构 — 三元结构

对齐 OBS obs_source_t + obs_source_info + context.data，用 C++ 纯虚基类替代 @protocol

WLSourceProtocol

C++ 纯虚基类 = ObjC @protocol。零数据成员，零实现代码（默认空 = @optional），纯接口约定。

WLSource（壳）

非多态、不被继承。持有 async_frames 缓冲 + backend 指针。控制方法透传 backend，析构第一行 delete backend_。

WLMediaSource

继承 WLSourceProtocol，持有 WLSource* 反向引用。解码线程通过 source_->OutputVideo() 回喂帧到壳的缓冲。
