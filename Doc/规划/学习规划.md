# 音视频流媒体开发职业规划

## 第一阶段

- **编程语言功底**：C / C++
- **图像格式基本概念**：RGB、YUV、JPG
- **FFmpeg**：常见编解码格式用法，写 MP4 容器
- **通讯协议**：网络 Socket 通讯，TCP/UDP 协议、RTMP、RTP
- **跨平台移植**：能将 C/C++ 代码移植到 iOS/Android，会写 C++ Qt
- **图形学入门**：至少完整读过一本 OpenCV / OpenGL 的入门著作，写过 demo 级别代码，知道原理

> 达到这样的水平，闭着眼睛都能拿 **30w 税后**。

## 第二阶段

可以试着研究音视频集大成者 **WebRTC**。从里到外，研究它个天翻地覆。这样，从一个小白，到大神，差不多 3 年时间可以办到。

> 这种人出去，年薪超过 **50 万税后**。

当然，第二步也可以不搞 WebRTC，可以搞**深度学习**，尤其是未来非常火爆的**边缘计算**，跟计算机视觉的结合。出去也是神一般的人物。当然目前这一块，资料比较少，需要自己摸索。
