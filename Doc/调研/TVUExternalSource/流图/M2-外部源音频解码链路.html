音视频同步的实际实现

音频被墙上时钟拉着走

  • externalSourceBaseTime 由视频的排序队列建立，音频只是等它
  • getFrontNodePts() 只窥探队头，不出队 —— 没到点就原样留在队列里
  • pts_offset = 30：允许比当前时间早 30ms 就放行
  • 视频链路卡住 → baseTime 不推进 → 音频跟着停，不会各跑各的

组播那条捷径

完全不经队列和编码线程

  • -decodeAudioWithCodetext:andPkt:andCurrentTimestamp:index: 在解析线程里直接软解
  • 重采样分包用 subcontractWithInBuffer:…SubcontractHandleBlock:
  • block 里就地判 PIP 决定进混音器还是 encode:
  • 同样要等 isVideoFirstF == YES
