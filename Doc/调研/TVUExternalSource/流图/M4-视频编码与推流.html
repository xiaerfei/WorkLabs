I 帧到底谁在决定

不是周期 GOP

  • streamType 或 streamSubType 变（切源）
  • exif LensModel 前后置翻转（切摄像头）
  • isFirst（开播首帧）
  • 外加 R 端下发的 forceInsertKeyFrame
  • GOP 常量 600 在 H.264 是秒（等于关掉周期 GOP），在 H.265 是帧

两条互斥推流链路

isEnableFrameTransfer 一个开关切换

  • 关：AVFormatControl::addH264Data → ASF mux → CTVUTransporterT
  • 开：TVULiveMediaCenter muxFrameWithStremId: → libtvulive2_mux_frame
  • I 帧的拼装顺序固定：SEI → SPS/PPS → 帧数据
  • 录制旁路与两者并行，走 TVURecordMuxHandler，不上网

dts 的两层兜底

保严格单调

  • dtsAfter = (pts − g_vstarttime) × 1000
  • 算出 0 → 用 last_dts + 33（假定 30fps）
  • 与上一帧相等 → +1
  • R 端看到的时间戳秩序，最后一道保障是 Mux 层的 Dispatch_Data() 交错
