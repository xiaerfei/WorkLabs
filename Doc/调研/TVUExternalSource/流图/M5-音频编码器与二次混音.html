index 守门是整块丢弃

不是静音，是整块不要

  • 条件：param->external_source_index != self.external_source_index
  • 屏录生效期间只收 100；DJI 接管期间只收 200
  • 混音器混出来的帧，index 必须取主源的 —— 取辅源就整块被丢
  • Accsoon 有例外开关 isLiveWithBulidInAudioStream 绕过判断

Agora 分叉的位置很关键

在守门之前

  • pushAudioData:andSampes:andTimestamp: 在 index 守门之前调
  • 所以 partyline 里听到的音源，可能与推到云端的不是同一路
  • 样本数：param->size / (2 * param->channel)
  • enableEncoding 为假时只走 Agora 不走编码

锁的范围

从守门到出包

  • mutex_lock 在 index 守门前拿，出包后 unlock
  • _audioConverter 为空时会先 unlock → setupEncoder → 重新 lock
  • 混音是就地覆盖 param->data，所以调用方的 buffer 会被改写
  • M2 里 TVUExtAudioEncoder 曾因为在锁里嵌套 cond_wait 死锁过（ITA-824）
