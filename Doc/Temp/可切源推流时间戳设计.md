##### User:

##### Assistant:


在 macOS 上做“像 OBS 一样可随时切源”的推流软件，时间戳设计的核心目标是：**对外（编码器/RTMP/RTSP/WebRTC 等）输出一条连续单调递增的时间线**，而内部各个源（摄像头、本地文件、屏幕采集）可以各用各的时间基准。切换源时做“时间线映射”，保证不会出现回退、跳变过大或音画不同步。

下面给你一套工程上比较通用、好落地的设计。

---

## 1）确定一条“输出主时间线”（Program Timeline）
建立一个全局的 `programClock`（主时钟），它是推流管线里**唯一**被用来生成最终 PTS/DTS 的基准。

- 时间基准建议用**单调时钟**：`mach_continuous_time()` / `mach_absolute_time()`（配合 timebase 转 ns）
- 单位统一用 `int64` 纳秒或 `CMTime`（推荐纳秒 int64，最后再转 `CMTime`/编码器时间基）
- `programPTS = nowMonotonic - programStartMonotonic + accumulatedPause`（如果支持暂停/恢复）

> 关键：无论源怎么切，`programPTS` 都只会单调递增。

---

## 2）每个源维护自己的“源时间线”与“映射参数”
对每个输入源（camera / file / screen / mic）维护两个概念：

1. **sourcePTS**：源帧自带的时间戳  
   - 摄像头/麦克风：通常来自 `CMSampleBufferGetPresentationTimeStamp`
   - 文件：来自 AVAssetReader 输出 sample 的 PTS
2. **映射到 program 的关系**：`programPTS = sourcePTS + offset`（最简单的线性映射）

当源被“切入”节目输出时，计算一次 offset：

- 设切入瞬间 `programNow`（当前主时间线）
- 设该源下一帧的 `sourceNextPTS`
- 令 `offset = programNow - sourceNextPTS`
- 之后该源每帧输出 `mappedPTS = sourcePTS + offset`

这样可以保证切入的第一帧时间戳正好跟节目时间线接上。

---

## 3）切源的两种模式：硬切 / 过渡（crossfade）
### A. 硬切（常见）
- 视频：切换时，新源第一帧的 `mappedPTS` 对齐当前 `programPTS`
- 音频：同理，建议做一个非常短的 fade-out/fade-in（5~20ms）避免爆音，但时间戳仍按 program 连续走

### B. 过渡（叠化、推拉等）
从时间戳角度仍然简单：**节目输出只有一条时间线**。过渡期间同时渲染两个源，但输出帧 `PTS` 依然来自 programClock（以渲染 tick/视频帧率来驱动）。

---

## 4）不要直接信任“源自带 PTS”用作最终输出
不同源的 PTS 特性差异很大：

- 摄像头：PTS 通常稳定但可能抖动、偶发跳变（驱动/系统负载）
- 文件：PTS 可能有 B 帧/DTS/可变帧率，读取时也可能不连续
- 屏幕采集：有时是“到达时间”而不是严格采样时钟

工程上建议：
- **最终输出 PTS 由 programClock 或 videoTick 生成**
- 源 PTS 主要用于：
  - 文件源按内容节奏读取
  - 音频源的采样对齐
  - 内部同步参考

---

## 5）视频建议：用“固定帧率的节目帧时钟”生成 PTS
OBS 类软件通常对外推流会选择一个目标 FPS（比如 30/60）。推荐做法：

- 设 `frameDuration = 1/fps`
- 每次输出一帧节目画面，`videoPTS = videoFrameIndex * frameDuration`（基于 programStart）
- 渲染线程按 vsync 或定时器 tick，如果某一时刻没有新源帧：
  - **复用上一帧（hold last frame）**，PTS 继续递增
- 切源时只是“内容换了”，视频时间戳不换逻辑

这样编码器最舒服（恒定帧率），CDN/播放器也更稳。

> 如果你必须支持 VFR，也仍建议输出端尽量 CFR，内部源再做适配。

---

## 6）音频建议：以音频为强时钟 or 使用 independent clock + 重采样
推流里最难的是音频连续性。两种常见策略：

### 策略 1：以音频为 master（常见于实时推流）
- 音频设备采样时钟稳定，输出音频按采样数累加：
  - `audioPTS += numSamples / sampleRate`
- 视频对齐到音频（videoPTS 依据 programClock，但 programClock 其实跟音频步进一致或被校正）

切换音频源（比如从麦克风到文件音轨）：
- 新音频源也用 offset 映射到当前 `audioPTS`
- 若两者采样率/时钟不同，需要 **resample**（AVAudioConverter / AudioConverter）

### 策略 2：programClock 为 master（渲染/系统时钟）
- 音频按 programPTS 排队播放，需要“拉伸/丢插样”维持与时钟一致（更复杂）
- 适合你有强渲染时钟、并且可以容忍轻微 time-stretch 的场景

多数 OBS-like 推流更接近策略 1 或者“音频驱动 + 视频追随”。

---

## 7）处理抖动与异常：timestamp smoothing / monotonic clamp
就算有映射，也建议加“安全阀”，避免出现回退或巨大跳变导致编码器报错：

- 单调递增约束：`mappedPTS = max(mappedPTS, lastPTS + minStep)`
  - 视频 `minStep` 可设为 0 或 1 tick（但最好不回退）
  - 音频 `minStep` 为至少一个 sample 的时长
- 对源 PTS 抖动做平滑：
  - 若 `abs(delta - expected) > threshold`，用到达时间/期望步进替代
- 对文件源 seek/loop：
  - seek 后 sourcePTS 会回到 0 或跳变，重新计算 offset 即可

---

## 8）实现结构建议（简单可维护）
可以抽象一个 `TimelineMapper`：

- `programClock.now()` -> `int64 programNowNs`
- `SourceState`:
  - `offsetNs`
  - `hasOffset`
  - `lastOutPTS`
- `map(sourcePTS)`:
  - 若未初始化：`offset = programNow - sourcePTS`
  - `out = sourcePTS + offset`
  - `out = max(out, lastOutPTS)`（或 +epsilon）
  - 更新 `lastOutPTS`

视频若采用 CFR，就更简单：**根本不需要用 sourcePTS 来算 outPTS**，只用 frame index；源只负责提供“最新画面”。

---

## 9）一个推荐的“最稳组合”
如果你要做得像 OBS 推流那么稳，我建议：

1. **节目输出视频使用 CFR**（例如 30/60），PTS 由 `frameIndex` 生成
2. **音频连续输出**（48k），PTS 由累计采样数生成
3. 切源只影响内容，不影响节目时间线；源进来时做 offset / 缓冲对齐
4. 对文件源：解码按其 PTS 读取，但输出到节目时按需要重采样/对齐

OBS 是如何设计的



##### Assistant:


OBS 的时间戳设计可以概括为一句话：**内部用“视频 tick + 音频采样”生成一条连续的节目时间线（program timeline），场景/源切换只换内容不换时间线**。它不会把“摄像头/文件自身的 PTS”直接当成对外输出时间戳，而是把各种源统一重采样/重定时到 OBS 自己的时钟体系里。

下面按 OBS 的实际架构思路拆开讲（不要求你完全照抄，但这是最稳的一类设计）。

---

## 1）核心：两条主节拍（Video Tick / Audio Samples）
### 视频：固定 FPS 的 tick 驱动
- OBS 有一个“视频线程/视频循环”，按你设置的输出 FPS（如 30/60）定时 tick。
- 每 tick：
  1. 从当前 Scene 拿到各个 source 的“最新纹理/帧”（可能是复用上一帧、也可能是新帧）
  2. 做合成（scene composition）
  3. 输出一帧到编码器
- **视频 PTS 通常就是 frame index 转时间**：  
  `video_pts = video_frame_count * (1/fps)`
- 如果某个源这一帧没更新，不影响 PTS：直接 hold last frame，节目仍按固定时间线前进。

这点对“切源”极其关键：切源不会造成时间戳突变，因为视频 PTS 根本不依赖某个源的 PTS。

### 音频：以“采样数”推进时间
- OBS 音频是以固定采样率（一般 48k）为核心。
- 音频的时间进度由累计输出样本数决定：
  `audio_time = total_samples / sample_rate`
- 各音频源（麦克风、媒体文件、桌面声等）进入 OBS 后会做：
  - 重采样到统一采样率（48k）
  - 按音频混音时钟对齐
  - 必要时做 drift 校正（防止设备时钟漂移）

---

## 2）对外输出时：A/V 对齐的策略
OBS 里实际编码/封装时通常是这么对齐的：

- **视频**：严格按视频 tick 的 PTS 走（CFR）
- **音频**：按音频块（例如每次 1024/960/2048 samples）输出，并带上对应的音频时间戳
- **A/V sync**：通过在混音/输出阶段做轻微的音频重采样（或丢/插样本）、或在视频侧延迟/对齐，让两者在同一条“节目时间线”上不会越跑越偏

简化理解：  
OBS 更像是“自己生成一个稳定的节目时钟”，然后把所有源塞进来适配它，而不是把源的时钟拿来主导输出。

---

## 3）切场景/切源时：为什么时间戳不会乱
在 OBS 里所谓“切场景”，本质是：
- 在某个视频 tick 上，合成器从 Scene A 切换到 Scene B（或者过渡期间混合两者）
- 编码器收到的仍然是**第 N 帧、第 N+1 帧**……时间戳连续

因此：
- **切换内容 ≠ 切换时间基准**
- 就算从摄像头切到文件，文件自己的 PTS 不会直接透传到输出；文件只是在每个 tick 提供它应该显示的画面（解码线程按自身节奏预解码，渲染线程按 tick 取用）。

---

## 4）源内部怎么“适配”OBS 时钟（媒体文件是重点）
媒体文件源（本地 mp4 等）在 OBS 里大致是：
- 解码线程根据文件时间戳解码出帧，放入队列
- 渲染 tick 到来时，根据“当前节目时间”选取最合适的一帧：
  - 太新的帧：先不显示（等）
  - 太旧的帧：丢掉
  - 近似的帧：取出来显示
- 音频同理：解码出 PCM 后，按音频混音时钟消费，必要时 resample/丢插维持同步

这就是典型的“**源驱动解码 + 节目时钟驱动呈现**”模型。

---

## 5）对推流封装层（FLV/RTMP、MKV 等）的时间戳
以常见的 RTMP/FLV 为例（OBS 很典型）：
- FLV 的时间戳字段是毫秒级，OBS 会把内部时间（ns 或基于 tick 的时间）转换成 ms 写入 packet
- 输出保证单调递增（或至少不回退）
- 如果编码器有 B 帧，内部还会处理 DTS/PTS（实际取决于编码器输出以及容器要求）；但对推流常见配置 OBS 往往偏向低延迟（少 B 帧）以减少复杂性和延迟

---

## 6）你做“类似 OBS”的关键结论（可以直接抄的设计要点）
如果你要复刻 OBS 的稳定性，建议你也这么做：

1. **输出端：用固定 FPS 的视频 tick 生成视频 PTS（CFR）**
2. **输出端：音频用固定采样率 + 累计样本数生成音频 PTS**
3. **所有源进来先适配（重采样/缓冲/丢帧/补帧）到节目时钟**
4. **切源只是切合成输入，不改节目时钟**
5. **永远保证对外时间戳单调递增**

#import <Foundation/Foundation.h>

static inline int64_t NSecFromSec(double sec) {
    return (int64_t)llround(sec * 1000000000.0);
}
static inline double SecFromNSec(int64_t ns) {
    return (double)ns / 1000000000.0;
}

#pragma mark - ProgramClock (monotonic based on mach_continuous_time)
#import <mach/mach_time.h>

@interface ProgramClock : NSObject
@property (nonatomic, readonly) int64_t startNS; // program start in ns (monotonic)
- (int64_t)nowNS;                             // monotonic ns
- (int64_t)programTimeNS;                     // now - start
@end

@implementation ProgramClock {
    mach_timebase_info_data_t _tb;
    uint64_t _startTicks;
}
- (instancetype)init {
    if ((self = [super init])) {
        mach_timebase_info(&_tb);
        _startTicks = mach_continuous_time();
    }
    return self;
}
- (int64_t)ticksToNS:(uint64_t)ticks {
    __uint128_t ns = (__uint128_t)ticks * _tb.numer / _tb.denom;
    return (int64_t)ns;
}
- (int64_t)nowNS {
    return [self ticksToNS:mach_continuous_time()];
}
- (int64_t)startNS {
    return [self ticksToNS:_startTicks];
}
- (int64_t)programTimeNS {
    return [self nowNS] - [self startNS];
}
@end

#pragma mark - SwitchingSource (content only)
typedef NS_ENUM(NSInteger, SimSourceKind) {
    SimSourceKindCamera,
    SimSourceKindFile,
};

@interface SwitchingSource : NSObject
@property (atomic) SimSourceKind kind;
- (NSString *)currentName;
@end

@implementation SwitchingSource
- (NSString *)currentName {
    switch (self.kind) {
        case SimSourceKindCamera: return @"camera";
        case SimSourceKindFile:   return @"file";
    }
}
@end

#pragma mark - VideoTicker (CFR PTS by frame index)
@interface VideoTicker : NSObject
@property (nonatomic, readonly) int fps;
@property (nonatomic, readonly) int64_t frameIndex;
@property (nonatomic, readonly) int64_t lastPTS;
- (instancetype)initWithFPS:(int)fps;
- (int64_t)nextPTSNS; // CFR: frameIndex * (1/fps)
@end

@implementation VideoTicker {
    int64_t _lastPTS;
    int64_t _frameIndex;
    int _fps;
}
- (instancetype)initWithFPS:(int)fps {
    if ((self = [super init])) {
        _fps = fps;
        _frameIndex = 0;
        _lastPTS = -1;
    }
    return self;
}
- (int)fps { return _fps; }
- (int64_t)frameIndex { return _frameIndex; }
- (int64_t)lastPTS { return _lastPTS; }

- (int64_t)nextPTSNS {
    // CFR PTS derived from frame index
    double t = (double)_frameIndex / (double)_fps;
    int64_t pts = NSecFromSec(t);

    // monotonic clamp (safety)
    if (_lastPTS >= 0 && pts < _lastPTS) pts = _lastPTS;

    _lastPTS = pts;
    _frameIndex += 1;
    return pts;
}
@end

#pragma mark - AudioTicker (PTS by cumulative samples)
@interface AudioTicker : NSObject
@property (nonatomic, readonly) int sampleRate;
@property (nonatomic, readonly) int blockSamples;
@property (nonatomic, readonly) int64_t totalSamples;
@property (nonatomic, readonly) int64_t lastPTS;
- (instancetype)initWithSampleRate:(int)sr blockSamples:(int)bs;
- (int64_t)nextPTSNS; // totalSamples / sampleRate
@end

@implementation AudioTicker {
    int _sr;
    int _bs;
    int64_t _totalSamples;
    int64_t _lastPTS;
}
- (instancetype)initWithSampleRate:(int)sr blockSamples:(int)bs {
    if ((self = [super init])) {
        _sr = sr;
        _bs = bs;
        _totalSamples = 0;
        _lastPTS = -1;
    }
    return self;
}
- (int)sampleRate { return _sr; }
- (int)blockSamples { return _bs; }
- (int64_t)totalSamples { return _totalSamples; }
- (int64_t)lastPTS { return _lastPTS; }

- (int64_t)nextPTSNS {
    double t = (double)_totalSamples / (double)_sr;
    int64_t pts = NSecFromSec(t);

    if (_lastPTS >= 0 && pts < _lastPTS) pts = _lastPTS;

    _lastPTS = pts;
    _totalSamples += _bs;
    return pts;
}
@end

int main(int argc, const char * argv[]) {
    @autoreleasepool {
        ProgramClock *clock = [ProgramClock new];
        SwitchingSource *source = [SwitchingSource new];
        source.kind = SimSourceKindCamera;

        int fps = 30;
        VideoTicker *video = [[VideoTicker alloc] initWithFPS:fps];

        int sr = 48000;
        int bs = 1024;
        AudioTicker *audio = [[AudioTicker alloc] initWithSampleRate:sr blockSamples:bs];

        // Sim length
        double durationSec = 8.0;

        // Event schedule: switch at 2s -> file, at 5s -> camera
        int64_t sw1 = NSecFromSec(2.0);
        int64_t sw2 = NSecFromSec(5.0);

        // We simulate two independent loops:
        // - video tick: every 1/fps
        // - audio tick: every bs/sr
        double videoStep = 1.0 / fps;
        double audioStep = (double)bs / (double)sr;

        double nextVideoT = 0.0;
        double nextAudioT = 0.0;

        int64_t lastVideoPTS = -1;
        int64_t lastAudioPTS = -1;

        while (YES) {
            int64_t progNS = [clock programTimeNS];
            if (SecFromNSec(progNS) >= durationSec) break;

            // switch source based on program time (this mimics user switching at arbitrary time)
            if (progNS >= sw1 && progNS < sw2) {
                source.kind = SimSourceKindFile;
            } else if (progNS >= sw2) {
                source.kind = SimSourceKindCamera;
            }

            // Determine which stream should emit next by scheduled time
            double progSec = SecFromNSec(progNS);

            BOOL doVideo = (progSec >= nextVideoT);
            BOOL doAudio = (progSec >= nextAudioT);

            if (!doVideo && !doAudio) {
                // sleep very short to avoid busy loop
                [NSThread sleepForTimeInterval:0.001];
                continue;
            }

            if (doVideo) {
                int64_t vPTS = [video nextPTSNS];
                // verify monotonic
                if (lastVideoPTS >= 0 && vPTS < lastVideoPTS) {
                    NSLog(@"VIDEO PTS BACKWARDS! last=%lld now=%lld", (long long)lastVideoPTS, (long long)vPTS);
                }
                lastVideoPTS = vPTS;

                LogVideoFrame(vPTS, [source currentName], video.frameIndex - 1, fps);
                nextVideoT += videoStep;
            }

            if (doAudio) {
                int64_t aPTS = [audio nextPTSNS];
                if (lastAudioPTS >= 0 && aPTS < lastAudioPTS) {
                    NSLog(@"AUDIO PTS BACKWARDS! last=%lld now=%lld", (long long)lastAudioPTS, (long long)aPTS);
                }
                lastAudioPTS = aPTS;

                LogAudioPacket(aPTS, [source currentName], audio.totalSamples - bs, sr, bs);
                nextAudioT += audioStep;
            }
        }

        NSLog(@"Done.");
    }
    return 0;
}

#import <Foundation/Foundation.h>
#import <mach/mach_time.h>

static inline int64_t NSecFromSec(double sec) { return (int64_t)llround(sec * 1e9); }
static inline double SecFromNSec(int64_t ns) { return (double)ns / 1e9; }

#pragma mark - ProgramClock (monotonic)
@interface ProgramClock : NSObject
- (int64_t)programTimeNS; // since start
@end

@implementation ProgramClock {
    mach_timebase_info_data_t _tb;
    uint64_t _startTicks;
}
- (instancetype)init {
    if ((self = [super init])) {
        mach_timebase_info(&_tb);
        _startTicks = mach_continuous_time();
    }
    return self;
}
- (int64_t)ticksToNS:(uint64_t)ticks {
    __uint128_t ns = (__uint128_t)ticks * _tb.numer / _tb.denom;
    return (int64_t)ns;
}
- (int64_t)programTimeNS {
    return [self ticksToNS:mach_continuous_time() - _startTicks];
}
@end

#pragma mark - TimelineMapper (source PTS -> program PTS)
@interface TimelineMapper : NSObject
@property (nonatomic) BOOL hasOffset;
@property (nonatomic) int64_t offsetNS;      // program = source + offset
@property (nonatomic) int64_t lastOutPTSNS;  // monotonic clamp

- (void)reset;
- (void)alignToProgramNow:(int64_t)programNowNS sourceNextPTS:(int64_t)sourceNextPTSNS;
- (int64_t)mapSourcePTS:(int64_t)sourcePTSNS minStepNS:(int64_t)minStepNS;
@end

@implementation TimelineMapper
- (instancetype)init {
    if ((self = [super init])) {
        _hasOffset = NO;
        _offsetNS = 0;
        _lastOutPTSNS = -1;
    }
    return self;
}
- (void)reset {
    _hasOffset = NO;
    _offsetNS = 0;
    _lastOutPTSNS = -1;
}
- (void)alignToProgramNow:(int64_t)programNowNS sourceNextPTS:(int64_t)sourceNextPTSNS {
    // Make the next source frame land at programNow
    _offsetNS = programNowNS - sourceNextPTSNS;
    _hasOffset = YES;
}
- (int64_t)mapSourcePTS:(int64_t)sourcePTSNS minStepNS:(int64_t)minStepNS {
    if (!_hasOffset) {
        // If caller forgets align, default to pass-through (not recommended)
        _offsetNS = 0;
        _hasOffset = YES;
    }
    int64_t out = sourcePTSNS + _offsetNS;

    // monotonic clamp to avoid going backwards
    if (_lastOutPTSNS >= 0) {
        int64_t floor = _lastOutPTSNS + minStepNS;
        if (out < floor) out = floor;
    }
    _lastOutPTSNS = out;
    return out;
}
@end

#pragma mark - Simulated Sources (generate "source PTS")
@protocol SimVideoSource <NSObject>
- (NSString *)name;
- (void)startAtProgramTime:(int64_t)programNowNS; // called when switching in
- (int64_t)produceNextSourcePTSNS; // source PTS for next frame
@end

/// Camera: source PTS roughly increases by frameDuration with small jitter
@interface SimCameraSource : NSObject <SimVideoSource>
- (instancetype)initWithFPS:(int)fps jitterNS:(int64_t)jitterNS;
@end

@implementation SimCameraSource {
    int _fps;
    int64_t _frameIndex;
    int64_t _jitterNS;
    int64_t _base; // start from 0 each activation? mimic device timeline reset
}
- (instancetype)initWithFPS:(int)fps jitterNS:(int64_t)jitterNS {
    if ((self = [super init])) {
        _fps = fps;
        _jitterNS = jitterNS;
        _frameIndex = 0;
        _base = 0;
    }
    return self;
}
- (NSString *)name { return @"camera"; }

- (void)startAtProgramTime:(int64_t)programNowNS {
    // For simulation: camera source PTS restarts from 0 each time it becomes active
    // (real cameras usually continue monotonic, but restart is a good stress test)
    (void)programNowNS;
    _frameIndex = 0;
    _base = 0;
}

- (int64_t)produceNextSourcePTSNS {
    double frameDur = 1.0 / (double)_fps;
    int64_t ideal = _base + NSecFromSec((double)_frameIndex * frameDur);

    // jitter in [-jitterNS, +jitterNS]
    int64_t r = (int64_t)arc4random_uniform((uint32_t)(_jitterNS * 2 + 1));
    int64_t jitter = r - _jitterNS;

    _frameIndex++;
    return ideal + jitter;
}
@end

/// File: source PTS increases by frameDuration, but we will simulate a SEEK (PTS jumps backwards)
@interface SimFileSource : NSObject <SimVideoSource>
- (instancetype)initWithFPS:(int)fps;
@property (atomic) BOOL shouldSeekBack; // when set, next call will jump backwards
@end

@implementation SimFileSource {
    int _fps;
    int64_t _frameIndex;
    int64_t _timelineBase; // in ns, starting at 0
}
- (instancetype)initWithFPS:(int)fps {
    if ((self = [super init])) {
        _fps = fps;
        _frameIndex = 0;
        _timelineBase = 0;
        _shouldSeekBack = NO;
    }
    return self;
}
- (NSString *)name { return @"file"; }

- (void)startAtProgramTime:(int64_t)programNowNS {
    (void)programNowNS;
    // typical file source: starts from 0 when (re)started
    _frameIndex = 0;
    _timelineBase = 0;
    _shouldSeekBack = NO;
}

- (int64_t)produceNextSourcePTSNS {
    if (_shouldSeekBack) {
        // simulate seek: jump back to earlier timestamp
        _shouldSeekBack = NO;
        // e.g. seek back to 0.5s
        int64_t seekTo = NSecFromSec(0.5);
        // Set internal index accordingly (roughly)
        _timelineBase = 0;
        _frameIndex = (int64_t)llround(0.5 * _fps);
        return seekTo;
    }

    double frameDur = 1.0 / (double)_fps;
    int64_t pts = _timelineBase + NSecFromSec((double)_frameIndex * frameDur);
    _frameIndex++;
    return pts;
}
@end

#pragma mark - Switching + Simulation
typedef NS_ENUM(NSInteger, ActiveSourceKind) {
    ActiveSourceKindCamera,
    ActiveSourceKindFile,
};

static void LogLine(NSString *tag,
                    int64_t programNS,
                    NSString *srcName,
                    int64_t srcPTS,
                    int64_t outPTS) {
    NSLog(@"%@ prog=%7.3f  src=%@  srcPTS=%7.3f  outPTS=%7.3f",
          tag,
          SecFromNSec(programNS),
          srcName,
          SecFromNSec(srcPTS),
          SecFromNSec(outPTS));
}

int main(int argc, const char * argv[]) {
    @autoreleasepool {
        ProgramClock *clock = [ProgramClock new];

        int fps = 30;
        int64_t frameStepNS = NSecFromSec(1.0 / fps);

        // two sources
        SimCameraSource *cam = [[SimCameraSource alloc] initWithFPS:fps jitterNS:NSecFromSec(0.003)]; // 3ms jitter
        SimFileSource *file = [[SimFileSource alloc] initWithFPS:fps];

        id<SimVideoSource> currentSource = cam;
        ActiveSourceKind currentKind = ActiveSourceKindCamera;

        // one mapper for "current video source -> program"
        TimelineMapper *mapper = [TimelineMapper new];

        // align initial source
        int64_t prog0 = [clock programTimeNS];
        [currentSource startAtProgramTime:prog0];
        int64_t firstSrcPTS = [currentSource produceNextSourcePTSNS];
        [mapper alignToProgramNow:prog0 sourceNextPTS:firstSrcPTS];

        int64_t lastOutPTS = -1;

        // schedule events
        int64_t switchToFileAt = NSecFromSec(2.0);
        int64_t doSeekAt      = NSecFromSec(3.5); // while file active, do a seek back
        int64_t switchToCamAt = NSecFromSec(5.0);

        // run for 7s
        int64_t endAt = NSecFromSec(7.0);

        // drive with a CFR tick (like OBS video thread)
        int64_t nextTickProgramNS = 0;

        while (YES) {
            int64_t progNS = [clock programTimeNS];
            if (progNS >= endAt) break;

            // wait until next tick
            if (progNS < nextTickProgramNS) {
                [NSThread sleepForTimeInterval:0.001];
                continue;
            }

            // handle switching events at tick boundaries (common in practice)
            if (progNS >= switchToFileAt && currentKind != ActiveSourceKindFile) {
                currentKind = ActiveSourceKindFile;
                currentSource = file;

                // important: reset source and realign mapper offset to program time
                [currentSource startAtProgramTime:progNS];
                int64_t nextSrcPTS = [currentSource produceNextSourcePTSNS];
                [mapper alignToProgramNow:progNS sourceNextPTS:nextSrcPTS];

                NSLog(@"---- SWITCH -> file at prog=%.3f ----", SecFromNSec(progNS));
                // Now we should output this first frame too (we already pulled nextSrcPTS)
                int64_t outPTS = [mapper mapSourcePTS:nextSrcPTS minStepNS:0];
                if (lastOutPTS >= 0 && outPTS < lastOutPTS) {
                    NSLog(@"ERROR: out PTS backwards on switch!");
                }
                lastOutPTS = outPTS;
                LogLine(@"[V]", progNS, [currentSource name], nextSrcPTS, outPTS);

                nextTickProgramNS += frameStepNS;
                continue;
            }

            if (progNS >= switchToCamAt && currentKind != ActiveSourceKindCamera) {
                currentKind = ActiveSourceKindCamera;
                currentSource = cam;

                [currentSource startAtProgramTime:progNS];
                int64_t nextSrcPTS = [currentSource produceNextSourcePTSNS];
                [mapper alignToProgramNow:progNS sourceNextPTS:nextSrcPTS];

                NSLog(@"---- SWITCH -> camera at prog=%.3f ----", SecFromNSec(progNS));
                int64_t outPTS = [mapper mapSourcePTS:nextSrcPTS minStepNS:0];
                if (lastOutPTS >= 0 && outPTS < lastOutPTS) {
                    NSLog(@"ERROR: out PTS backwards on switch!");
                }
                lastOutPTS = outPTS;
                LogLine(@"[V]", progNS, [currentSource name], nextSrcPTS, outPTS);

                nextTickProgramNS += frameStepNS;
                continue;
            }

            // simulate a seek while file is active
            if (progNS >= doSeekAt && currentKind == ActiveSourceKindFile) {
                // trigger seek once
                if (!file.shouldSeekBack) {
                    file.shouldSeekBack = YES;
                    NSLog(@"---- FILE SEEK BACK triggered at prog=%.3f (next srcPTS will jump) ----",
                          SecFromNSec(progNS));
                }
            }

            // normal tick: produce a source PTS and map it to output PTS
            int64_t srcPTS = [currentSource produceNextSourcePTSNS];

            // Option A: map with monotonic clamp minStep=0 (allow equal PTS, not recommended for encoders)
            // Option B: enforce at least 1ns increment to guarantee strict monotonic
            int64_t minStep = 1; // 1ns to keep strictly increasing
            int64_t outPTS = [mapper mapSourcePTS:srcPTS minStepNS:minStep];

            if (lastOutPTS >= 0 && outPTS < lastOutPTS) {
                NSLog(@"ERROR: out PTS backwards!");
            }
            lastOutPTS = outPTS;

            LogLine(@"[V]", progNS, [currentSource name], srcPTS, outPTS);

            nextTickProgramNS += frameStepNS;
        }

        NSLog(@"Done.");
    }
    return 0;
}

1. **切到 file** 时：`file` 的 `srcPTS` 从接近 0 开始，但 `outPTS` 会对齐到当前 `prog` 附近，且延续上一个 outPTS（不会回到 0）。

##### Assistant:


1) **CFR（Constant Frame Rate，恒定帧率）**  
指输出视频的帧率是固定的，比如始终 30fps 或 60fps。

- 表现：每两帧之间的时间间隔固定  
  - 30fps：每帧间隔约 33.333ms  
  - 60fps：每帧间隔约 16.667ms
- 时间戳特点：视频 PTS 按固定步进增长，例如  
  `PTS(n) = n * (1/fps)`
- 工程意义（像 OBS 常用的方式）：  
  即使某个源此刻没有新画面（摄像头卡顿、文件解码慢），也会**照样输出一帧**（复用上一帧/黑帧），时间戳仍然连续、稳定，编码器和推流端更“舒服”，播放器也更稳定。

适用场景：直播推流（RTMP/SRT 等）、希望稳定码率/稳定延迟/兼容性更好时。

---

2) **VFR（Variable Frame Rate，可变帧率）**  
指输出视频的帧率不固定，什么时候有新帧就什么时候输出，帧与帧之间的间隔可能不一样。

- 表现：有时 10ms 来一帧，有时 50ms 来一帧，间隔不均匀
- 时间戳特点：PTS 依据实际帧到达/源时间戳增长，例如  
  `PTS` 序列可能是：0ms, 33ms, 66ms, 120ms, 153ms ...
- 工程意义：  
  更贴近“源原本的节奏”（尤其是屏幕录制、手机录像、部分 VFR 文件），但对编码器缓冲、封装、播放器的兼容性要求更高；推流链路上更容易出现抖动、音画不同步、缓存策略复杂等问题。

适用场景：离线录制、保留原始节奏、或者某些对端明确支持 VFR 的链路。

---

### 用一句话帮你区分
- **CFR**：你按“节拍器”固定频率输出帧；没新画面就重复上一帧，但时间戳严格等间隔。  
- **VFR**：帧什么时候来就什么时候出，时间戳跟着真实间隔走。

如果你做的是“类似 OBS 的直播推流软件”，通常更推荐 **CFR（视频）+ 固定采样率（音频）**，切源时只换内容，不换时间线。
